# First Project

Connected with **GitHub**, **Vercel**, and **Supabase**.

## Setup & Environment
1. Clone repository:
   ```bash
   git clone https://github.com/sajibahhamed-beep/first-project.git
   ```
2. Copy `.env.example` to `.env.local` and add your API keys:
   ```bash
   cp .env.example .env.local
   ```

## Tech Stack
- Frontend: HTML5, Modern Vanilla CSS3, JavaScript (ES6+)
- Database: Supabase
- Hosting & CI/CD: Vercel
- Version Control: GitHub
